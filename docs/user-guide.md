### Working with lists

Every list works like a ServiceNow list:

- **Sort:** click a column heading (again to reverse).
- **Column menu (⋮):** sort, group by, ungroup.
- **Right-click a cell:** *Show matching* or *Filter out* (Shift+F10 from the keyboard).
- **Breadcrumb:** shows filters, grouping and sort; × removes one.
- **Columns:** choose which columns to show (remembered in this browser).
- **Open list / Copy query / Export:** open the same records in a ServiceNow list, copy the encoded query, or download what is shown as CSV.

## 3. Settings (admins)

**Configuration → Properties** (or the **Settings** tab) is visible to app admins only. Each setting has an ⓘ that explains it. Changes apply after **Save settings**.

## 4. Tips

Close a tip with × to hide it until you next sign in, or select **Don't show again** to hide it for good in this browser.
